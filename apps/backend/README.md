To install dependencies:

```sh
npm install
```
After syncing all dpendencies u will need create your own .env 
whos example can be found in backend/.env.example

To run:

```sh
npm run dev
```

To migrate latest db changes use:

```sh
npm run db:migrate
```

To generate a migration snapshot use:

```sh
npm run db:generate
```

To run a local db gui use:

```sh
npm run db:studio
```

open http://localhost:3000
